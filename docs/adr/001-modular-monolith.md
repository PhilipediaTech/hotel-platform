# ADR-001: Modular monolith: one API codebase, one HTTP process, one worker process

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Simple to run and cheap; module boundaries keep it splittable.

## Decision

Modular monolith: one API codebase, one HTTP process, one worker process.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
