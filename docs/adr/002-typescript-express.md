# ADR-002: TypeScript + Express 5 instead of NestJS

- **Status:** Accepted (supersedes Strategy §16)
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Team already ships Express; TypeScript catches money and permission errors early.

## Decision

TypeScript + Express 5 instead of NestJS.
