# ADR-005: Staff app is a static React + Vite PWA; Astro for booking and marketing pages; no Next.js server

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Free static hosting, offline caching, SEO only where needed.

## Decision

Staff app is a static React + Vite PWA; Astro for booking and marketing pages; no Next.js server.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
