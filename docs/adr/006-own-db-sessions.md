# ADR-006: Own server-side sessions in the database, httpOnly cookie, TOTP MFA

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Revocable sessions, no per-user identity fees.

## Decision

Own server-side sessions in the database, httpOnly cookie, TOTP MFA.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
