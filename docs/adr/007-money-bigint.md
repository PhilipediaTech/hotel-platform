# ADR-007: Money as BigInt minor units + ISO currency; percentages as basis points; FX as micro-units

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

No floating-point errors.

## Decision

Money as BigInt minor units + ISO currency; percentages as basis points; FX as micro-units.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
