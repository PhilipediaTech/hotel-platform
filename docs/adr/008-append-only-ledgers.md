# ADR-008: Folio lines, payments, audit events and alert outcomes are append-only (DB triggers); corrections are reversals

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Tamper-evidence and trustworthy reports.

## Decision

Folio lines, payments, audit events and alert outcomes are append-only (DB triggers); corrections are reversals.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
