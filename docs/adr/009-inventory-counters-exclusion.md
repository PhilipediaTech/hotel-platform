# ADR-009: Room-type inventory counters with conditional updates + exclusion constraint on room allocations

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Prevents overselling and double assignment under concurrency.

## Decision

Room-type inventory counters with conditional updates + exclusion constraint on room allocations.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
