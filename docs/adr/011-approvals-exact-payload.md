# ADR-011: Approvals store the exact action payload and re-validate before executing

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Approver sees and approves exactly what runs.

## Decision

Approvals store the exact action payload and re-validate before executing.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
