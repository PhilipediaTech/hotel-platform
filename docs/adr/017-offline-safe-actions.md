# ADR-017: Offline: read cache + whitelisted safe actions only; money actions need a connection

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Integrity over availability for money.

## Decision

Offline: read cache + whitelisted safe actions only; money actions need a connection.

## Consequences

See the Architecture and Stack tab (2) for how this is applied.
