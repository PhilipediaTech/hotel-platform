# ADR-018: Tenant isolation in the application layer first, PostgreSQL RLS added in V1.1

- **Status:** Accepted
- **Source:** Master Specification v3.0, tab 10 (Decision Log)

## Context

Ship safely now, add defence in depth once schema settles.

## Decision

Tenant isolation in the application layer first, PostgreSQL RLS added in V1.1.
